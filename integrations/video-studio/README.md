# Galley 视频工坊

把一篇已发布的文章做成配了音的视频的本地工具：一个只在本机监听的小服务，加一个网页。

它做的事：

1. 向 Galley 要已发布文章的清单（`/narration.json`）让你选，再要选中那一篇的讲稿（`/posts/<别名>/narration.json`），按播放的顺序一拍一拍列出来：每一页的 `:::notes`、场景每一步的 `say`；
2. 调用本机的配音 MCP 服务，给每一拍有讲稿的生成声音，拿到时长和逐句的字幕；
3. 把每一拍的时长传给 Galley 的演示页（`timing` 参数），嵌在页面里自动播放。演示每走到一拍通知一声，工具就放这一拍的声音、按时间出字幕——声音跟的是画面实际走到的位置；
4. 录成视频（画面、声音、字幕一起），或者只导出字幕文件。

字幕由这个工具加在画面底部：演示用 `captions=space` 把底部那一条空出来了，不会盖住内容，也不用加黑边。

## 准备

- 在 Galley 后台的「MCP 管理」里接入一个 Agent，拿到访问密钥。工具用它读讲稿（讲稿不公开）。
- 一个配音的 MCP 服务，在 `~/.claude.json` 的 `mcpServers` 里登记过（默认找名字叫 `my-voice-tts` 的）。它要有一个 `generate_voiceover` 工具：收 `{ text, output_path }`，返回 `{ audio_path, duration_seconds, subtitle_cues: [{ start, end, text }] }`。

## 启动

```bash
GALLEY_URL=https://你的站点 GALLEY_TOKEN=你的密钥 pnpm studio
```

然后打开 <http://localhost:4321>，在上面的下拉里选一篇文章（清单里标着每篇写了几处讲稿），再点「生成配音」→「预览」。文章改过讲稿以后点「重新读取」。

密钥不要写进会提交的文件里。可以放进 shell 的配置，或者写在一个单独的文件里，用 `GALLEY_TOKEN_FILE` 指过去。

| 环境变量 | 作用 | 默认 |
|---|---|---|
| `GALLEY_URL` | Galley 的地址 | `http://localhost:3000` |
| `GALLEY_TOKEN` / `GALLEY_TOKEN_FILE` | 访问密钥，或者只写着密钥的文件 | 无 |
| `STUDIO_PORT` | 工具监听的端口 | `4321` |
| `STUDIO_DIR` | 生成的音频存在哪里 | `~/galley-studio` |
| `STUDIO_TTS_SERVER` | 配音服务在 `~/.claude.json` 里登记的名字 | `my-voice-tts` |
| `STUDIO_TTS_COMMAND` | 不从 `~/.claude.json` 里读时，直接给出配音服务的启动命令 | 无 |

## 要知道的几件事

- **配音会缓存。** 每一拍的声音按讲稿的内容存着，讲稿没改就不会重新生成；改了哪一拍，只重新生成那一拍。
- **配音模型占内存。** 模型在第一次生成时加载，之后一直留着。用完点「释放模型内存」，或者关掉工具。
- **录制成片**用的是浏览器的标签页录制：点了以后在弹出的窗口里选「这个标签页」，并勾上「同时分享标签页中的音频」，否则录不到声音。需要 Chrome 或 Edge。
- **导出字幕**是按每一拍的时长排出来的。文章里有代码演变、算法动画这类自己走节奏的播放器时，那几页之后的时间会偏；这种文章用「录制成片」，字幕直接录在画面里。
- 这个服务只在本机监听（`127.0.0.1`）：它能启动配音进程、能往磁盘写文件，不该让局域网里的别人访问到。
- 不是每篇文章都要做视频：没写讲稿的拍不配音，按 Galley 建议的时长停。
